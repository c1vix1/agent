# agent

A dumb agent with tools to help you every day (really me).

**install the ESP32 side at

Built on a ESP32 with a screen

Agent currently lets you fetch event from google calender, fetch google classroom assignment via calender ID, control your [home-assistant.io](Home Assistant), track a your PiHole Instance, and control your computer's volume.

- [ ] Timer Control
- [ ] Google calender
- [ ] Google Classroom
- [ ] Home assistant
- [ ] PiHole
- [ ] Computer volume
- [ ] Task Manager
